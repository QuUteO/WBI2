# Telnet Client — Консольный TCP-клиент

Проект представляет собой консольную утилиту на языке Go для подключения к TCP-серверам и интерактивного обмена данными через сетевое соединение. Программа реализует базовую функциональность telnet-клиента: устанавливает TCP-соединение с удаленным сервером, передает пользовательский ввод в сокет и отображает ответы сервера в терминале.

## Функциональные возможности

### 1. Установление TCP-соединения

**Подключение к удаленному серверу:**
Утилита принимает адрес хоста и номер порта в качестве аргументов командной строки и устанавливает TCP-соединение с указанным сервером.

**Настраиваемый таймаут подключения:**
Поддержка параметра `--timeout` для ограничения времени ожидания установки соединения. По умолчанию используется таймаут 10 секунд.

**Обработка ошибок подключения:**
При невозможности установить соединение программа завершается с информативным сообщением об ошибке.

### 2. Интерактивный обмен данными

**Передача пользовательского ввода:**
Все данные, вводимые пользователем через STDIN, немедленно отправляются в открытое TCP-соединение.

**Получение ответов сервера:**
Все данные, поступающие из сокета, выводятся в STDOUT без дополнительной обработки.

**Режим реального времени:**
Ввод и вывод выполняются одновременно, что обеспечивает полноценное интерактивное взаимодействие с удаленным сервисом.

### 3. Корректное завершение работы

**Завершение по Ctrl+D:**
При получении EOF из STDIN (комбинация клавиш Ctrl+D) клиент закрывает соединение и завершает выполнение.

**Обработка закрытия соединения сервером:**
Если сервер завершает соединение, клиент автоматически завершает свою работу.

**Освобождение ресурсов:**
Все сетевые соединения корректно закрываются перед завершением программы.

### 4. Конкурентная обработка ввода и вывода

**Раздельные горутины:**
Чтение данных из STDIN и чтение данных из сокета выполняются в отдельных горутинах.

**Отсутствие блокировок ввода/вывода:**
Пользователь может одновременно отправлять данные серверу и получать ответы.

**Безопасная работа с сетью:**
Используется тип `net.Conn`, который поддерживает конкурентное чтение и запись без возникновения гонок данных.

## Архитектура проекта

Приложение построено по простой модульной схеме и состоит из следующих компонентов:

### Сетевой слой

Отвечает за установление TCP-соединения через пакет `net`.

Функции:

* подключение к серверу через `net.DialTimeout`;
* управление жизненным циклом соединения;
* обработка сетевых ошибок.

### Слой ввода

Отвечает за чтение пользовательских данных из STDIN.

Функции:

* получение пользовательского ввода;
* передача данных в TCP-соединение;
* обработка EOF (Ctrl+D).

### Слой вывода

Отвечает за получение данных от сервера и отображение их пользователю.

Функции:

* чтение данных из сокета;
* вывод данных в STDOUT;
* завершение работы при закрытии соединения сервером.

## Требования

* Go версии 1.18 или выше.
* Стандартная библиотека Go (`net`, `io`, `os`, `flag`, `time`).

## Сборка и запуск

### Компиляция проекта

```bash
go build -o telnet-client main.go
```

### Запуск программы

```bash
./telnet-client <host> <port>
```

Пример:

```bash
./telnet-client localhost 8080
```

### Запуск с пользовательским таймаутом

```bash
./telnet-client --timeout=5s localhost 8080
```

## Особенности реализации

* Используется `net.DialTimeout` для ограничения времени подключения.
* Передача данных осуществляется через `io.Copy`.
* Ввод и вывод работают в отдельных горутинах.
* Корректно обрабатывается завершение по Ctrl+D.
* Клиент автоматически завершает работу при закрытии соединения сервером.
* Реализация не содержит гонок данных и соответствует идиоматическому стилю Go.
